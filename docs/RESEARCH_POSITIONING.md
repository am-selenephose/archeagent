# Archeagent Research Positioning

Archeagent does not claim that multi-agent orchestration, sandboxing, code review, budgets, or audit trails are novel by themselves.

The research hypothesis is the closed-loop combination of:

1. contextual agent reliability rather than one global model score;
2. counterfactual shadow evaluation to reduce selection bias;
3. implementer-reviewer pair intelligence;
4. post-deployment outcome feedback;
5. calibrated authority promotion;
6. risk-adaptive verification;
7. signed proof-carrying release leases;
8. exact-head, exact-patch, exact-policy, and exact-evidence fencing;
9. explicit cost and reviewer-attention budgets.

The future provider-backed benchmark should compare static best-model routing, cost-only routing, task-class routing, contextual Archeagent routing, and contextual routing plus reviewer-pair optimization.

Required outcome metrics include verified task success, escaped defects, security regressions, cost, latency, reviewer minutes, rollback and hotfix rate, calibration error, and cumulative routing regret.

A meaningful claim must survive held-out repositories or task classes.
