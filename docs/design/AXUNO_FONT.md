# Archeagent AXUNO font status

The approved original reference is AXUNO by VPcreativeshop / Only Fonts.
The file AxunoDemo-Regular.otf was located in the owner's Downloads and is
used only in the private local preview for design verification. The original
demo license is personal-use only. It is intentionally omitted from GitHub,
from all commits and from any public distribution.

The approved local interface uses the exact AXUNO demo for branding and short
display headings on the owner's laptop. Jost remains the operational face for
body text, labels, controls and evidence. Geist Mono supplies tabular numeric
data. Unsupported AXUNO digits and punctuation use fallback. The asset and
letterforms are unmodified; do not claim another geometric font is identical.

Working local asset: public/fonts/axuno-original-demo.otf (ignored).
Private CSS preview rule: end of src/app/pearl-theme.css.
The local completion pass protects this private asset with project ignore
rules; no shared Git configuration changes are part of the workbench repair.

The root layout includes a page-local `darkreader-lock` meta tag so Dark Reader
does not recolor the deliberately authored pearl and obsidian surfaces. It does
not change extension settings or any other page. Moving material layers remain
continuous in normal motion and stop under `prefers-reduced-motion: reduce`.

Final public release blocker: obtain the actual AXUNO Webfont asset under
a license that permits the intended website embedding and traffic. Only then
replace the private demo preview rule and perform production browser QA.
Do not apply cosmetic glyph edits as a substitute for licensing.
